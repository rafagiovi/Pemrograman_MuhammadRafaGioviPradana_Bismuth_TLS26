Deskripsi Repositori

Repositori ini berisi berkas penyelesaian Tugas Pemrograman Dasar TLS 2026 yang terdiri dari dua fase:

Fase 1 (Logika & Algoritma): Disajikan dalam bentuk dokumen laporan (laporan_fase1.pdf) yang memuat pseudocode untuk Problem 1 (The Last Astronaut), flowchart untuk Problem 2 (Alien-In-The-Middle), serta penjelasan alur logika masing-masing minimal 2 paragraf.

Fase 2 (Implementasi C++): Source code program C++ murni untuk kedua problem yang ditulis secara mandiri (user-defined functions) tanpa library fungsi bawaan selain header <iostream>.
